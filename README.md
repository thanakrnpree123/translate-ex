# translate-ex — อ่านออกเสียงแบบฝึกหัด

เว็บแอปที่รันในเครื่อง Mac สำหรับทำไฟล์เสียงและวิดีโอเฉลยแบบฝึกหัด
อัปโหลดรูปแบบฝึกหัด (หรือทั้งโฟลเดอร์) → โปรแกรมอ่านโจทย์ภาษาไทยจากรูป แปลเป็นคำตอบภาษาอังกฤษ (หรือภาษาอื่น)
→ สร้างเสียงอ่าน (ใช้เสียงของคุณเองได้) → บันทึกเป็นวิดีโอขนาดเล็กลงโฟลเดอร์ `ex` ข้างรูปต้นฉบับ

ใช้กับเอกสาร PDF / Word / TXT แบบอ่านทั้งหมดได้ด้วย

## ความสามารถ

- **อ่านข้อความจากรูป (OCR)** ด้วย Vision ของ macOS รองรับไทยและอังกฤษ ไม่ต้องติดตั้งเพิ่ม
- **โหมดแบบฝึกหัดทีละข้อ** แยกข้อที่มีเลขกำกับ (`1. …`, `2. …`) แปลคำตอบให้ แก้คำตอบได้ก่อนสร้างเสียง
  แล้วอ่านเป็น "ข้อ 1. (โจทย์ไทย)" → เว้นให้คิด → "(คำตอบ)" → ข้อต่อไป
- **โหมดอ่านทั้งหมด** อ่านข้อความทั้งไฟล์ เลือกแปลก่อนอ่านได้
- **12 ภาษา** ไทย อังกฤษ จีน ญี่ปุ่น เกาหลี เวียดนาม ฝรั่งเศส เยอรมัน สเปน รัสเซีย อินโดนีเซีย มาเลย์ เลือกเสียงชาย/หญิงและความเร็วได้
- **เสียงของฉัน** อัดเสียงตัวเองครั้งเดียว แล้วให้คำตอบอ่านด้วยเสียงของคุณ (ประมวลผลในเครื่อง ไม่ส่งเสียงออกไปไหน)
- **อัปโหลดหลายไฟล์หรือทั้งโฟลเดอร์** ค้นโฟลเดอร์ย่อยให้ ข้ามรูปที่มีวิดีโอใน `ex` แล้ว และสร้างเสียงทีละไฟล์ตามคิว
- **วิดีโอขนาดเล็ก** รูป + เสียง ประมาณ 0.4–0.8 MB ต่อหน้า (ประหยัดพื้นที่ Google Drive) เปิดได้ทุกเครื่อง
- **บันทึกลงโฟลเดอร์ ex อัตโนมัติ** กดปุ่มเดียว วิดีโอไปอยู่ข้างรูปของแต่ละ Unit แล้วลบออกจากรายการให้

## สิ่งที่ต้องมี

- macOS (ใช้ OCR ของ Vision) — ทดสอบบน Mac Intel, macOS 26
- Python 3.11 (`brew install python@3.11`) — PyTorch บน Mac Intel ใช้ได้ถึงรุ่น 2.2.2 ซึ่งไม่รองรับ Python 3.13+
- ffmpeg (`brew install ffmpeg`)
- อินเทอร์เน็ต สำหรับเสียงอ่าน (Microsoft Edge TTS) และการแปล (Google Translate)

## ติดตั้งและเปิดโปรแกรม

```bash
git clone https://github.com/thanakrnpree123/translate-ex.git
cd translate-ex
./start.command
```

หรือดับเบิลคลิก `start.command` ใน Finder ครั้งแรกจะติดตั้งไลบรารีให้เอง (หลายนาที ใช้พื้นที่ประมาณ 1.3 GB)
แล้วเบราว์เซอร์จะเปิดที่ http://127.0.0.1:5055
โมเดลแปลงเสียง (125 MB) จะดาวน์โหลดเองตอนสร้างเสียงของฉันครั้งแรก

## วิธีใช้กับโฟลเดอร์แบบฝึกหัด

สมมติว่ารูปเก็บแบบนี้:

```
Downloads/
  L1SPhoto Unit46-50/
    L1SPhoto Unit46/
      46.1.png  46.2.png  …
    L1SPhoto Unit47/
      47.1.png  …
```

1. (ครั้งแรก) ที่ส่วน **เสียงของฉัน** อัดเสียงตัวเอง 30–60 วินาที ในที่เงียบ แล้วกดบันทึก
2. กด **📁 เลือกทั้งโฟลเดอร์** แล้วเลือก `L1SPhoto Unit46-50` (หรือลากโฟลเดอร์มาวาง)
3. เลือกโหมด **แบบฝึกหัดทีละข้อ**, ภาษาของคำตอบ และ **เสียงที่ใช้อ่าน**
4. ตรวจหรือแก้คำตอบในแต่ละไฟล์ แล้วกด **สร้างเสียงทั้งหมด** (ทำทีละไฟล์)
5. ที่ **รายการที่บันทึกไว้** ตั้งโฟลเดอร์ที่เก็บรูป (เช่น `~/Downloads`) แล้วกด **บันทึกวิดีโอทั้งหมดลงโฟลเดอร์ ex**

ผลลัพธ์:

```
L1SPhoto Unit46/ex/46.1.mp4
L1SPhoto Unit47/ex/47.1.mp4
```

ถ้าบันทึกไฟล์เดิมซ้ำ จะแทนที่ด้วยอันล่าสุด ถ้าหารูปต้นฉบับไม่เจอหรือเจอหลายที่ จะไม่บันทึกและบอกเหตุผล

## เคล็ดลับเสียงของฉัน

- พูดต่อเนื่อง 30–60 วินาที ช่วงเงียบจะถูกตัดออก (ต้องเหลือเสียงพูดอย่างน้อย 10 วินาที)
- อ่านทั้งภาษาไทยและภาษาอังกฤษ ด้วยน้ำเสียงแบบเดียวกับที่อยากได้ในไฟล์
- อยู่ในห้องเงียบ ปากห่างไมค์ประมาณหนึ่งคืบ
- วิธีนี้เปลี่ยน**สีเสียง**ให้เป็นของคุณ (OpenVoice V2) แต่จังหวะและสำเนียงยังมาจากเสียงสำเร็จรูป
  เพศของเสียงต้นแบบเลือกให้อัตโนมัติจากระดับเสียงของคุณ
- ในโหมดแบบฝึกหัด โจทย์อ่านด้วยเสียงสำเร็จรูป ส่วนคำตอบอ่านด้วยเสียงของคุณ

## ไฟล์ที่โปรแกรมเก็บ (ไม่ถูก commit)

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `saved/<วันเวลา>_<ชื่อไฟล์>_<ภาษา>/` | `original.*`, `audio.mp3`, `video.mp4` (เฉพาะรูป), `text.txt`, `info.json` |
| `voices/<id>/` | เสียงตัวอย่าง (`sample.wav`) และลายเสียง (`se.pth`) ของคุณ |
| `uploads/` | ไฟล์ที่อัปโหลดชั่วคราว |
| `models/` | โมเดลแปลงเสียง OpenVoice |
| `config.json` | โฟลเดอร์ที่ใช้บันทึกลง `ex` ล่าสุด |

## ข้อจำกัด

- PDF แบบสแกน (ไม่มีข้อความในไฟล์) ยังอ่านไม่ได้ ให้แปลงเป็นรูปก่อน
- การแปลใช้ Google Translate แบบไม่มีคีย์ ถ้าใช้ถี่มากอาจโดนจำกัดชั่วคราว โปรแกรมจะสลับช่องทางและลองใหม่ให้
- เสียงของฉันบนเครื่อง Mac Intel ใช้ CPU: แบบฝึกหัด 12 ข้อใช้เวลาประมาณ 3 นาที

## โครงสร้างโค้ด

- `app.py` — เซิร์ฟเวอร์ Flask: OCR, แยกข้อ, แปล, สร้างเสียง, วิดีโอ, บันทึกลง `ex`, จัดการเสียงผู้พูด
- `voice.py` — แปลงเสียงด้วย OpenVoice V2 (ทำความสะอาดเสียงตัวอย่าง, สร้างลายเสียง, แปลงเสียง)
- `templates/index.html` — หน้าเว็บทั้งหมด (HTML + CSS + JS ในไฟล์เดียว)
- `start.command` — ติดตั้งครั้งแรกและเปิดโปรแกรม
